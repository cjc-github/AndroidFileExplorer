## 一、核心需求（项目立项的四条）

### 1. 设备发现与目录浏览

- [x] 发现**本机** Android 设备（adb，`LocalAdbTransport`）
- [x] 发现**远程机器**上的 Android 设备（MDD 协议，`RemoteEngineTransport`）
- [x] 浏览设备的文件目录结构（`ls -la`，toybox 兼容）
- [x] 面包屑导航，逐级可点击返回上级
- [x] 路径直达框（如 `/data/local/tmp`）
- [x] 访问受限目录时报错并说明原因（403 + 中文提示 + root 指引）
- [x] 多台机器并发同步设备清单（`asyncio.gather`，单机故障不拖慢整体）
- [x] 设备唯一标识跨重连稳定（`sha1("hw|" + ro.serialno)`）
- [x] 同一台设备经多个 agent 发现只登记一次（设备身份不依赖接入路径）
- [x] 远程机器命令连接池（默认 4 条常驻 MDD 连接，不同设备命令互不排队；坏连接自愈、机器刚失败时短暂跳过）
- [x] 同一台机器只登记一次（`(kind, host, port)` 唯一索引，重复登记返回 400）

### 2. 文件拉取与上传

- [x] 从设备拉取文件（设备 → agent → 服务器暂存 → **浏览器下载**，`GET .../files/download`）
- [x] 设备侧 agent 实现文件传输协议（`FILE_PUSH` 字节流 + md5 校验 / `FILE_PULL` 回传字节流 + md5 校验）
- [x] 上传本地文件到设备指定目录（`push` / multipart 上传）
- [x] 上传流式落盘（分块写盘，2GiB 上限不再整体进内存；推送后删除暂存副本）
- [x] 落地文件唯一命名（不同设备同名文件不互相覆盖）+ 过期自动清理（`STAGING_MAX_AGE_HOURS`，默认 24h）
- [x] 文件大小、权限、属主、修改时间展示
- [x] 命令注入防护（设备路径白名单，`$(id)` / `;` / `` ` `` / `|` 等一律 400）

### 3. 运行状态轮询

- [x] 前台按平台设置刷新设备运行状态（默认 3 秒）
- [x] CPU 使用率（圆形进度条）
- [x] CPU 硬件信息：核心数（/proc/cpuinfo）+ 最高频率（cpufreq sysfs，垃圾值防御）+ SoC 平台（ro.board.platform），圆环下方副标题展示，模拟器无有效值时正确留空
- [x] CPU 实时频率：`scaling_cur_freq` 随指标一起采样，多核取平均，圆环下方显示「当前 / 最高」频率
- [x] 存储用量：同一次 shell 采集 `/data`、`/sdcard` 的 `df -k`，列表显示用量条，详情抽屉显示已用 / 总量 / 百分比
- [x] 服务端排序：设备名、最后在线按全量数据排序（跨页有效）
- [x] 设备详情抽屉：完整软硬件属性、指标、存储、root 与时间信息
- [x] 内存使用率 + 已用 / 总量（圆环下方上下排列）
- [x] 指标采集缓存（2.5s TTL，避免重复打设备）
- [x] 设备品牌 / 型号展示（`getprop` 惰性缓存）
- [x] root 状态探测缓存（15s TTL，root/unroot 后自动失效，轮询不再每次打设备）
- [x] 设备列表指标并发采样（多设备互不排队）

### 4. 唯一标识与生命周期

- [x] 每台机器（engine）与设备（device）入库并绑定唯一 UID
- [x] 设备连接 / 断开（网络设备 `adb connect` / `disconnect`）
- [x] 设备在线 / 离线 / 异常 / 未授权状态流转
- [x] 主动断开等用户操作与"设备自己掉线"区分展示
- [x] 设备别名（alias）：设备名可点击改名，列表即显
- [x] 是否 root 实时探测（`id` → `uid=0`），表格独立 Root 列（是/否）
- [x] 设备静态属性入表：CPU 架构（`ro.product.cpu.abi`）、Android 版本 + API level（一次 `getprop` 全量采集，惰性缓存，落库）
- [x] 轮询路径的设备属性变更真正落库（修复 `list_devices` 从不 commit 的缺陷）
- [x] 设备表操作列的单台 root 开关（尝试 root / 取消 root，按状态切换文案；UI 点击 → Root 列实时翻转）

## 二½、SSH 直连接入（第二种远程接入方式，零部署）

- [x] 新增 `SshAdbTransport`：Web 界面填 SSH 用户名/密码即可接入，远程机器**无需部署任何组件**
- [x] 机器列表视觉对齐设备页：双行名称（主名 + 接入方式副标题）、语义色标签（本机 adb / agent / SSH 直连）、地址一键复制、设备数层次、错误信息省略+气泡
- [x] 功能与 agent 方式完全对等（设备发现 / 文件 / 指标 / root / 批量 / 设置——全部继承自 `Transport` 抽象）
- [x] 文件传输走 SFTP（设备 → 远程临时文件 → SFTP 回传服务器 → 浏览器）
- [x] SSH 密码按机器存库，API 永不回显（仅返回 `has_ssh_password` 布尔）；也支持不填密码走本机密钥
- [x] 远程 `adb` 不在 PATH 时可指定路径（`adb_path`）
- [x] 真机验证：128 → 130 SSH 通道完成设备发现 / 指标 / 文件浏览 / 下载 / 上传 / root 开关全链路
- [x] 单元测试：进程内 asyncssh 服务器验证密码认证三态（正确 / 错误 / 缺省回落密钥）

## 五、自包含架构

- [x] 设备侧 agent 收进本项目（`agent/agent.py`，仅依赖 Python 标准库 + adb）

- [x] agent 停止脚本（pid 文件 + `SHUTDOWN` 指令）
- [x] agent 命令白名单（只执行 adb 命令，其它一律拒绝）

- [x] agent adb 进程并发上限（`--max-concurrent`，默认 8）：多设备命令可并行
- [x] DB 轻量自动迁移（启动时补列，如 `token` / `alias` / `is_rooted` / `is_network_device`）
- [x] SQLite WAL（并发同步任务写库不再 `database is locked`）
