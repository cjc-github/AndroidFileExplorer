## 一、核心需求（项目立项的四条）

### 1. 设备发现与目录浏览

- [x] 发现**本机** Android 设备（adb，`LocalAdbTransport`）
- [x] 发现**远程机器**上的 Android 设备（MDD 协议，`RemoteEngineTransport`）
- [x] 浏览设备的文件目录结构（`ls -la`，toybox 兼容）
- [x] 面包屑导航，逐级可点击返回上级
- [x] 路径直达框（如 `/data/local/tmp`）
- [x] 访问受限目录时报错并说明原因（403 + 中文提示 + root 指引）
- [x] 多台机器并发同步设备清单（`asyncio.gather`，单机故障不拖慢整体）
- [x] 设备唯一标识跨重连稳定（`sha1("hw|" + ro.serialno)`）
- [x] 同一台设备经多个 agent 发现只登记一次（设备身份不依赖接入路径）

### 2. 文件拉取与上传

- [x] 从设备拉取文件（设备 → agent → 服务器暂存 → **浏览器下载**，`GET .../files/download`）
- [x] 设备侧 agent 实现文件传输协议（`FILE_PUSH` 字节流 + md5 校验 / `FILE_PULL` 回传字节流 + md5 校验）
- [x] 上传本地文件到设备指定目录（`push` / multipart 上传）
- [x] 文件大小、权限、属主、修改时间展示
- [x] 命令注入防护（设备路径白名单，`$(id)` / `;` / `` ` `` / `|` 等一律 400）

### 3. 运行状态轮询

- [x] 前台每 3 秒刷新设备运行状态
- [x] CPU 使用率（圆形进度条）
- [x] 内存使用率 + 已用 / 总量（圆环下方上下排列）
- [x] 指标采集缓存（2.5s TTL，避免重复打设备）
- [x] 设备品牌 / 型号展示（`getprop` 惰性缓存）

### 4. 唯一标识与生命周期

- [x] 每台机器（engine）与设备（device）入库并绑定唯一 UID
- [x] 设备连接 / 断开（网络设备 `adb connect` / `disconnect`）
- [x] 设备在线 / 离线 / 异常 / 未授权状态流转
- [x] 主动断开等用户操作与"设备自己掉线"区分展示
- [x] 设备别名（alias）：设备名可点击改名，列表即显
- [x] 是否 root 实时探测（`id` → `uid=0`），表格独立 Root 列（是/否）
- [x] 设备静态属性入表：CPU 架构（`ro.product.cpu.abi`）、Android 版本 + API level（一次 `getprop` 全量采集，惰性缓存，落库）
- [x] 轮询路径的设备属性变更真正落库（修复 `list_devices` 从不 commit 的缺陷）
- [x] 设备表操作列的单台 root 开关（尝试 root / 取消 root，按状态切换文案；UI 点击 → Root 列实时翻转）

## 五、自包含架构

- [x] 设备侧 agent 收进本项目（`agent/agent.py`，仅依赖 Python 标准库 + adb）
- [x] agent 协议与平台端一一对应（`命令执行成功` 信封 + `===END===`）
- [x] 一键部署：`scripts/install-agent.sh`（停旧 → 传输 → 启动 → 自检 → 登记）
- [x] 通过 MDD 通道自举部署（无需 SSH 免密）
- [x] agent 停止脚本（pid 文件 + `SHUTDOWN` 指令）
- [x] agent 命令白名单（只执行 adb 命令，其它一律拒绝）

- [x] DB 轻量自动迁移（启动时补列，如 `token` / `alias` / `is_rooted` / `is_network_device`）
