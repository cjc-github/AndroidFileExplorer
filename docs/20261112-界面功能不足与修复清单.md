# 界面功能不足与修复清单（2026-11-12）

> 范围：只讨论界面已经展示的页面及其对应功能，不包含登录/鉴权、部署、TLS、CI 等外围事项。
>
> 状态标记：`[ ]` 未开始 · `[~]` 处理中 · `[x]` 已完成（本清单 29 项已全部完成）

## 一、设备资源页 `/devices`

- [x] **1. 设备状态会“假在线”**
  - 首次进入用 `refresh=true`，之后轮询用 `refresh=false`；设备拔掉后指标采集失败被静默吞掉，状态不变。
  - 默认 `auto_sync_seconds=0` 时，页面可能一直显示「在线」、CPU/内存一直「采样中…」、最后在线时间停更。
  - 目标：轮询失败达到阈值后把设备状态刷新为离线/异常，或在轮询中做轻量状态探测。
  - 相关：`frontend/src/pages/devices/DevicesPage.tsx`、`backend/app/api/routes/devices.py`、`backend/app/services/metrics.py`

- [x] **2. 轮询导致整表 loading 闪烁**
  - `loading={devicesQuery.isFetching}` 配合 3 秒轮询，每次后台刷新整张表都盖遮罩。
  - 目标：只在首屏加载时显示 loading，后台轮询不遮挡表格。

- [x] **3. 行级按钮 loading 是全局的**
  - `rootSwitchMutation.isPending`、`connectMutation.isPending`、`disconnectMutation.isPending` 没有按 uid 区分。
  - 目标：点哪台设备，只有那一行的按钮转圈；机器页「测试连接」同样按行区分。

- [x] **4. 批量 root 只报总数**
  - 接口返回每台设备的 `message`，前端只统计成功数，失败设备没有原因。
  - 目标：逐台展示失败设备与失败原因；失败设备保留选中便于重试。

- [x] **5. CPU/内存列对离线/权限不足设备也显示「采样中…」**
  - 无法区分「首次采样」和「根本采不到」。
  - 目标：在线且首次采样显示「采样中…」；离线/异常/无权限显示「离线」「无权限」或「-」。

- [x] **6. 设备页缺少过滤/排序，且 alias 显示不一致**
  - 设备页没有过滤/排序；文件选择页有过滤但不匹配 alias。
  - 目标：设备页增加按 alias/model/serial/uid/brand 过滤；选择页和文件页统一优先显示 alias。

- [x] **7. 改名入口不明显，错误信息撑高行**
  - 改名只有点击设备名；错误列长文本没有截断/Tooltip。
  - 目标：改名处增加编辑图标/提示；错误列 ellipsis + Tooltip。

## 二、文件选择页 `/files`

- [x] **8. 每 5 秒做一次全量同步**
  - `getDeviceList(true)` + 5 秒轮询，会重新探测所有机器；开启自动 root 时还会周期性触发 root。
  - 目标：首次进入全量同步一次，之后走轻量列表查询；刷新间隔跟随平台设置。

- [x] **9. 查询失败被当成「没有设备」**
  - 查询失败时直接显示空状态，没有错误提示和重试。
  - 目标：增加错误 Alert + 重试按钮，空状态只在请求成功且确实无设备时显示。

- [x] **10. 选择页不显示 alias/品牌**
  - 显示名不读 alias，过滤也不匹配 alias/brand。
  - 目标：显示名优先 alias，过滤包含 alias 与 brand。

## 三、文件浏览页 `/devices/{uid}/files`

- [x] **11. 搜索永远从根目录开始**
  - 点搜索强制 `setPath("/")`，不搜当前目录，placeholder 也没说明范围。
  - 目标：支持「当前目录 / 全设备」搜索范围，并在界面上明确展示。

- [x] **12. 搜索无结果时仍显示「该目录为空」**
  - 空状态文案与搜索状态不符。
  - 目标：搜索无结果显示「没有匹配的文件」。

- [x] **13. 设备详情请求失败没有错误态，状态标签是英文**
  - uid 不存在或接口失败时控制栏正常、表格显示空目录；设备状态直接用原始英文值。
  - 目标：增加设备加载失败提示；状态标签走统一的 `deviceStatusLabel`。

- [x] **14. 符号链接目录点不进去，链接目标不展示**
  - 解析时符号链接 `is_dir=false`，行点击只判断 `is_dir`；`link_target` 接口返回但界面不展示。
  - 目标：链接行可尝试进入（非目录时给出提示）；展示链接目标。

- [x] **15. 批量删除无限并发且只报第一条错误**
  - `Promise.allSettled` 同时发所有删除请求；失败提示只有数量和第一条原因，与文档「逐项反馈」不符。
  - 目标：限制并发；逐项展示成功/失败结果；失败项保留选中。

- [x] **16. 上传能力太弱**
  - 不支持多选、无进度、无取消、按钮无 loading、同名直接覆盖无提示，大文件还会被 60 秒超时中断。
  - 目标：支持多文件顺序上传、单文件进度与取消、上传中禁用按钮、覆盖前确认；上传请求不套用 60 秒全局超时。

- [x] **17. 下载失败没有页面提示，大文件无进度**
  - 点击后只提示「正在下载」；403/404/502 时浏览器可能直接打开或下载错误 JSON。
  - 目标：下载错误在页面提示；支持进度与取消（大文件可降级为浏览器直接下载并明确提示）。

- [x] **18. 重命名只能同目录改名**
  - 后端支持移动到其它路径，界面没有暴露；也没有复制、移动、chmod/chown、预览、排序、整目录下载。
  - 目标：重命名弹窗支持目标目录；补充排序；其余大功能按可行性逐项评估实现。

- [x] **19. 文件名链接样式对文件无效，列表无分页/继续加载**
  - 文件行看起来可点击但点击无反应；只有搜索结果有 200 条截断提示。
  - 目标：只对可进入的条目使用链接样式；列表增加明确的截断/加载状态说明。

## 四、远程机器页 `/machines`

- [x] **20. 机器没有编辑入口**
  - 名称、密钥、adb 路径、SSH 凭据只能删除重建，删除会连带删掉设备记录。
  - 目标：增加编辑机器弹窗；密钥/密码留空表示不修改。

- [x] **21. 无法判断 SSH 机器是否已保存密码**
  - 接口 `has_ssh_password` 恒为 false，界面也没有展示。
  - 目标：修正后端字段计算并在列表中明确展示「已保存密码 / 使用本机密钥」。

- [x] **22. 机器查询失败显示「暂无机器」**
  - 没有错误态和重试。
  - 目标：增加错误 Alert + 重试；空状态只在请求成功时显示。

- [x] **23. 删除机器不清理 transport 缓存**
  - 删除后重新登记同一机器，实际请求可能仍走旧连接/旧凭据。
  - 目标：删除/更新机器时同步注销缓存并关闭连接。

## 五、设置页 `/settings`

- [x] **24. 设置读取失败时页面没有错误提示**
  - 目标：增加错误 Alert + 重试。

- [x] **25. 刷新间隔只对设备页生效**
  - 文件页固定 3 秒、选择页固定 5 秒，用户会以为改的是全站。
  - 目标：设备页、选择页、文件页统一读取平台设置；明确说明作用范围。

- [x] **26. 自动同步/自动 root 语义与文案不完全一致**
  - 「自动同步=0 只在点同步时刷新」不完全成立；自动 root 每个同步周期实际执行两次。
  - 目标：去掉重复执行；修正文案或在首次加载/后台同步行为上保持一致。

## 六、跨页面

- [x] **27. 列表查询失败普遍被当成空数据**
  - 设备页、机器页、选择页、设置页都没有「加载失败」提示。
  - 目标：统一增加错误态与重试（文件列表已有 Alert）。

- [x] **28. 轮询把 `isFetching` 当 loading 用**
  - 3–5 秒一次整表 spinner，应区分首屏加载与后台刷新。
  - 目标：表格 loading 只使用首屏状态；后台刷新不遮挡。

- [x] **29. alias 只在设备页生效**
  - 文件页、选择页、文件页头部都不读 alias，命名体验不统一。
  - 目标：所有设备列表/头部统一使用 `alias ?? model ?? serial`。
