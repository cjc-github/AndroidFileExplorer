关于本预览稿

这是静态 HTML 提案稿，用于预览与收集意见。工程内任何源码文件均未被修改——确认方向后才执行落地。

所有数据均为演示用假数据，但列名、状态语义、字段口径与现有 DevicesPage.tsx / README 一一对齐，避免"好看但落不了地"。

可预览的交互
· 顶栏太阳/月亮按钮 → 切换浅色 / 深色两套色板
· 侧栏 ☰ → 232 / 64px 折叠
· 左侧菜单 → 切换四个页面
· 设备表表头 → 排序 + 位移动画
· 全局搜索 → 过滤 + 空状态
· 文件页 → 环形进度与空状态演示
· 设置页 → 保存三态与开关/滑块
界面优化提案 · 待你拍板

现状：功能 29 项已全部完成，但仍是 antd 默认白底皮肤、96px 纯图标侧栏、顶栏一行灰字——信息层级薄、无品牌识别。本稿只做设计系统化，不新增功能；工程文件未改动，确认后才执行。
